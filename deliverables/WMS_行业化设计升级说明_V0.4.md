# 精细化工 WMS 行业化设计升级说明 V0.4

**适用范围：**第一阶段 WMS 业务需求与可交互原型。  
**编制日期：**2026-11-13。  
**实施原则：**人工决策为主；系统负责展示提示、业务执行、状态与数量记录及全链路追溯。  

## 1. 行业物料主数据

- 建立物料编码、名称、别名、分层行业类别、物理形态、规格/浓度、计量单位、默认包装、复检周期、效期、SDS与仓储提示等字段。
- 化学识别字段支持 CAS、UN 编号（适用时）和资料版本，增加字段来源、核验状态、核验人、日期。未经甲方核验的危险属性和储存要求必须标为“待核验”。
- 分类示例：无机化工原料、有机溶剂、聚合物/树脂、助剂/催化剂、粉体填料、半成品、产成品及研发样品。
- 物理形态示例：液体、粉末、颗粒、浆料、块状、液化气体、其他。
- 示例物料：液氨、甲醇、氢氧化钠溶液、钛白粉、聚醚多元醇、聚醚大单体、聚羧酸减水剂母液；全部用于演示，实际危险性、安全条件和配存须由甲方专业人员核验。

## 2. 标准业务字典

| 字典分组 | 建议字典值 |
|---|---|
| 物料类别 | 无机化工原料、有机溶剂、聚合物、粉体填料、助剂、半成品、产成品 |
| 形态 | 液体、粉末、颗粒、浆料、液化气体 |
| 包装方式 | 钢桶、PE塑料桶、IBC吨桶、纸塑袋、吨袋、散装/罐装 |
| 库位类别 | 原料区、成品区、待检区、隔离区、样品区、罐位（预留） |
| 质检结论 | 待检、合格、不合格、待处理 |
| 复检提醒 | 未到期、临近、到期、超期、已登记 |
| 库存处置 | 正常、待确认、受限、冻结、隔离 |
| 包装状态 | 完好、破损、标签异常、封口异常 |
| 收货差异 | 短收、超收、批号不符、重量偏差、包装破损 |
| 计量来源 | 人工实称、外部称重凭证、标准重量换算、设备自动（预留） |
| 库存调整 | 盘盈、盘亏、位置更正、计量更正、损耗登记 |
| 人工让步 | 待检处理、质检异常、复检异常、特殊用途、其他 |
| 发货点检 | 批次一致、包装完好、标签清晰、数量核对、随货资料 |

系统控制状态码与可维护业务字典分离；字典启停和重命名不得无痕改变历史业务含义。

## 3. 实物编码及库存身份

- 区分物料码、内部批次码、外部批号、包装实物码、托盘码、库位码。
- 默认管理批次+包装规格+托盘；逐桶/逐袋唯一编码按甲方管理精度条件启用。
- 条码换标、补打、拆分与重新关联保留来源、目标、数量、操作人员与原因。
- 组托/拆托、库存数量分段与真实混料/批次合并/形态转换严格区别；涉及生产或质量属性改变的场景需另行确认。

## 4. 包装及计量口径

区分包装件数、单件标准净重、理论净重、毛重、皮重、实际净重、业务执行量、库存账面量、预留量和可执行量。固定重量包装可按标准计算，变重包装以经确认的实际量为准。收货发生重量差异时保留两种口径、差异值、计量来源和处理说明，不得静默按理论值替换。

## 5. 收货、上架及出库

- 收货支持同物料多批次、短收超收、标签异常、破损、批号不符及实重差异；退货根据实际情况进入待检、隔离或待确认。
- 上架展示候选库位、容量及同物料/同批次分布，实际选择由库管员决定；不强制自动配存。
- 出库展示批次、生产日期、有效期、复检、质检、状态、包装、位置、托盘、账面/预留/可执行量与风险提示；推荐排序仅供人工参考。
- 销售出库可按制度增加批次、包装、标签、件数、净重、随货资料等点检记录；点检不直接改变账面库存，出库只在唯一确认节点一次性扣账。

## 6. 质量、复检及部分库存状态

初检结论、历次更正、复检历史、库存处置及人工让步分开保存。复检到期只提醒、不自动报废，库存状态对实际数量段生效。例如同批次800kg中冻结200kg，其余600kg仍为另一库存段，数量总额不变。质量不合格并不自动转为“让步合格”。

## 7. 人工让步与责任归属

授权应明确批次、库存对象、允许业务、上限数量、用途、批准依据、批准人和有效期（适用时）；执行记录实际数量、执行人和时间。审批与执行可以按制度由同人或不同人承担，但分别留痕。业务放行不能豁免法律法规或强制性安全条件。

## 8. 行业化原型与示例数据

增加行业物料主数据及字典页面；使现有样例增加物理形态、专业类别、包装状态、资料核验状态；支持标准重量与实称差异、库位与批次候选提示、销售发货点检及质量历史展示。原型中所有安全敏感信息均应标注“演示/待核验”。

## 9. 优先级及范围

**优先增强：**主数据/字典、包装计量、数量段库存、质量/复检历史、授权记录、候选信息、库存守恒与追溯。  
**待确认：**单桶唯一码、线边仓及余料、罐位台账、仓库巡检、交付点检强制规则、真实批次合并。  
**本期不含：**ERP/MES/QMS接口、生产投料、独立实验过程、电子称重设备实时采集、地磅/DCS/PLC/AGV/WCS、自动危险品配存判定、TMS、复杂3D大屏。

需在甲方评审确定业务范围后重新评估工作量，不能直接把新增项视为原有200人天估算内的既定承诺。
