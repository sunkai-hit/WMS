## 范围边界

- **保留**：批次级库存、收发存、货位/库位、包装及单位换算、实体托盘组拆、质检/复检业务节点、人工让步、授权例外、盘点、追溯、条码移动作业。
- **不设计**：检验分析方法、指标检验与实验过程、复杂电子质检报告、ERP/MES/QMS 接口、生产投料防错、复杂危化品自动配存规则。
- **操作原则**：质检结论与放行决定分离。具备权限的人员可进行例外操作，保留原因、人员、时间、数量和库存变化记录。
- **注意**：当前原型数据是演示数据；需另行完成真实数据库、接口和生产级部署。

## 版本约定

详细修订版 Word 是最新文字说明基线。Excel 与 HTML 仍标为 V0.3，后续需求变更应同步更新三个文件，避免范围偏差。
