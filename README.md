## 当前业务范围

标准收发存、批次级库存、库位库存、包装/单位换算、托盘组托拆托、质检与复检业务节点、人工让步与授权例外、盘点、库存流水、批次追溯及条码移动作业。

**核心原则：人工决定业务放行与处置；系统负责信息提示、授权操作、库存事务正确性和操作留痕。** 不开发独立的检验分析方法、检验指标、实验过程及检验报告服务；ERP/MES/QMS 系统对接和生产投料防错不在本阶段范围内。

## 项目使用约定

1. 需求文档是当前范围基线，原型用于业务验证和界面沟通。
2. 模拟业务数据不得视为正式库存。
3. 后续若引入开源 WMS 底座，应单独记录其原始许可证、保留声明、技术版本和二次开发变更。
4. 所有影响库存数量、批次、质量结论或让步处置的变更，需保持可追溯。
